# Captures de référence

Ce répertoire conserve des illustrations historiques de l’interface Mergeron :
conversation, approbations, branches, fichiers, intégrations et terminal. Elles
servent de supports visuels de référence, pas de source de vérité sur l’écran actuel.

Les fichiers `*-en.png` présentent une interface en anglais. Ils ne constituent
ni des tests exécutables ni une preuve de validation d’une modification récente.
Les contrôles visuels actuels produisent leurs propres captures temporaires ;
ne pas remplacer ces références par des captures contenant des données privées.

Voir [Vérification visuelle](../docs/verification-visuelle.md).
